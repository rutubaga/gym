# gym

Одностраничное приложение: дневник тренировок, чередование А → Б → В и трекер.
Открывается двойным кликом по `тренировки-v2.html`, работает офлайн, без сборки и зависимостей.
Отметки подходов хранятся в localStorage браузера.

## Вкладки

- **Тренировка** — текущий день, десятичные веса с точкой или запятой, кг/lb, галочки и кнопка «Записать». Можно добавить подход или несколько частей с разным весом внутри одного подхода.
- **Программа** — три тренировки А → Б → В при плавающем графике. При двух занятиях в неделю: А–Б, затем В–А, затем Б–В. Рабочие веса заполняются самостоятельно.
- **Тело** — история веса, мышечной массы и процента жира; подробности InBody и графики. Новые замеры хранятся только в браузере. Повторное сохранение даты дополняет запись без потери остальных показателей.
- **Спина и кор** — ежедневная рутина на 8–10 минут и трекер серии.
- **Прогресс** — динамика по упражнениям: рабочий вес и оценка 1ПМ, регулярность по месяцам.
- **История** — расшифровка дневника с 01.02.2026, плюс всё записанное в приложении.
- **Почему так** — устройство новой программы, прогрессия и правила записи подходов.

## Устройство

Данные и логика внутри HTML:

- `HISTORY` — расшифрованный дневник тренировок.
- `DAYS` — программа: дни, упражнения, количество подходов `s`, диапазон повторов `r`, варианты `options` и пояснения `cue`.
- `log` — черновики. Подход содержит `segments`: вес `w`, единицу `unit` (`kg`/`lb`) и повторы `r` для каждой части.
- `custom[].detail` — завершённые подходы с исходными единицами и группировкой частей. `custom[].e` — совместимое представление для графиков и тоннажа, вес в кг.
- `ROUTINE` — ежедневная рутина на осанку.
- `SRC` — источники.

Графики нарисованы вручную в SVG, внешних библиотек нет.

## Сохранение

Новая программа хранится в `train-v3`. При первом запуске записи истории, замеры и отметки рутины копируются из `train-v2`. Старые черновики показываются в архиве во вкладке «История»; их индексы не переносятся на новые упражнения. Исходный ключ `train-v2` остаётся нетронутым. Экспорт JSON включает всё состояние новой версии и копию старого состояния.

Переключатель единиц вверху меняет единицу у пустых полей и новых подходов. Заполненные веса остаются в прежних единицах. Переключатель рядом с конкретным весом задаёт единицу введённого числа, без автоматического изменения самого числа. В истории lb сохраняются как lb; в графиках и приблизительном тоннаже переводятся в кг по коэффициенту 0.45359237.

## Проверка

`node --test tests/gym.test.cjs`

Проверяются обработчики приложения, составные подходы, дробные значения, единицы веса, цикл А–Б–В, валидация и перенос старых данных. Это проверка логики с подменой DOM, а не визуальный браузерный тест.
